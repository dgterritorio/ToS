# Terms of use

## Machine-readable version

The terms of use are also available in machine-readable formats:

- [JSON](terms-of-use.json)

These representations structure the information on this page for use by applications and other systems.

## 1. Scope

These terms establish the general conditions for using the public OGC APIs provided by the Directorate-General for Territory (DGT).

Use of the API must comply with applicable legislation, the data licence conditions and the technical conditions defined in this documentation.

## 2. Responsible use

Users should avoid behaviour that could degrade the service or impair access by other users.

In particular, automated applications should:

- use pagination;
- apply filters where available;
- limit concurrent requests;
- avoid unnecessary repeated requests;
- reuse results where appropriate;
- avoid unnecessarily large queries;
- implement appropriate handling of errors and temporary service unavailability.
