# Access and discovery

## Base URL

**https://ogcapi.dgterritorio.gov.pt/**

The Landing Page is the starting point for discovering the service, collections and available representations.

## Representations

The API provides representations intended for people and machines, including HTML, JSON, JSON-LD and OpenAPI.

The OpenAPI documentation can be discovered from the Landing Page through the service's standard links.

## Authentication

Public DGT OGC APIs do not require authentication unless otherwise stated by the service.

## Conformance

The conformance classes actually implemented by the service can be consulted at:

[Consult the conformance declaration](https://ogcapi.dgterritorio.gov.pt/conformance)

The declaration published by the service is the reference for the behaviour of the version currently in production.

## Collections

Available collections can be consulted at:

[Consult the available collections](https://ogcapi.dgterritorio.gov.pt/collections)

Specific information for each collection is available through the API itself.
