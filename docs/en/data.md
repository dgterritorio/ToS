# Data and updates

## Metadata

Information about each collection is available in the metadata published by the API and, where applicable, in [SNIG](https://snig.dgterritorio.gov.pt/) and [dados.gov.pt](https://dados.gov.pt/).

## Updates

The update frequency depends on the production cycle of each dataset.

The date of the latest update and other relevant information can be consulted in the metadata of the respective collection.

## SNIG and dados.gov.pt

The OGC APIs provide a technical access point to DGT geographic data.

[SNIG](https://snig.dgterritorio.gov.pt/) is the discovery and publication point for geographic information and its metadata.

[dados.gov.pt](https://dados.gov.pt/) is the cross-government access point for open data, including high-value datasets (HVD).
