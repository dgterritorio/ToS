# OGC API of the Directorate-General for Territory

## Using the API to access geographic data

The **OGC APIs of the Directorate-General for Territory (DGT)** provide access to geographic information for applications and other systems, using open standards from the **Open Geospatial Consortium (OGC)**.

The API allows geographic information to be queried and integrated into applications, Geographic Information Systems (GIS), Web services and automated processing workflows.

## How to use

1. Discover the available collections on the [Landing Page](https://ogcapi.dgterritorio.gov.pt/).
2. Consult the [OpenAPI specification](https://ogcapi.dgterritorio.gov.pt/openapi).
3. Identify the appropriate operation and parameters.
4. Use pagination and filters to avoid unnecessary data transfers.
5. Check the metadata and licence applicable to the collection.
6. For automated use, follow the recommendations in the [terms of use](terms.md).

!!! note "Information status"
    This documentation complements the technical information provided by the API. The OpenAPI specification is the reference for the operations and parameters currently supported by the service.
