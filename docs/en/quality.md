# Service quality

## Quality indicators

For the purpose of monitoring service quality, the following indicators are considered:

### Availability

- **Availability/reliability (%):** percentage of checks completed successfully during the reference period.
- **Success rate (%):** proportion of checks that received a valid response.

### Performance

- **Average response time (seconds):** average response time observed during the checks performed.
- **95th percentile response time (seconds):** value below which 95% of the observed response times fall.

### Capacity

- **Concurrent requests:** number of requests that the service can handle simultaneously, according to the tests performed.
- **Requests per minute:** number of requests that the service can handle during the test period while maintaining the defined quality criteria.
