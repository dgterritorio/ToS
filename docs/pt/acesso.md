# Acesso e descoberta

## URL base

**https://ogcapi.dgterritorio.gov.pt/**

A Landing Page é o ponto inicial para descobrir o serviço, as colecções e as representações disponíveis.

## Representações

A API disponibiliza representações destinadas a pessoas e a máquinas, incluindo HTML, JSON, JSON-LD e OpenAPI.

A documentação OpenAPI pode ser descoberta a partir da Landing Page através das relações normalizadas do serviço.

## Autenticação

O acesso às OGC API públicas da DGT não requer autenticação, salvo indicação específica no próprio serviço.

## Conformidade

As classes de conformidade efectivamente implementadas devem ser consultadas em:

[Consultar a declaração de conformidade](https://ogcapi.dgterritorio.gov.pt/conformance)

A lista publicada no serviço constitui a referência para o comportamento da versão actualmente em produção.

## Coleções

As coleções disponíveis podem ser consultadas em:

[Consultar as coleções disponíveis](https://ogcapi.dgterritorio.gov.pt/collections)

A informação específica de cada colecção está disponível na própria API.
