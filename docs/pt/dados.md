# Dados e actualização

## Metadados

A informação sobre cada colecção está disponível nos metadados publicados pela API e, quando aplicável, no [SNIG](https://snig.dgterritorio.gov.pt/) e no [dados.gov.pt](https://dados.gov.pt/).

## Actualização

A frequência de actualização depende do ciclo de produção de cada conjunto de dados.

A data da última actualização e outras informações relevantes podem ser consultadas nos metadados da respectiva colecção.

## SNIG e dados.gov.pt

As OGC API constituem um ponto de acesso técnico aos dados geográficos da DGT.

O [SNIG](https://snig.dgterritorio.gov.pt/) constitui o ponto de descoberta e disponibilização de informação geográfica e respectivos metadados.

O [dados.gov.pt](https://dados.gov.pt/) constitui o ponto transversal de acesso a dados abertos da Administração Pública, incluindo os conjuntos de dados de elevado valor (HVD).
