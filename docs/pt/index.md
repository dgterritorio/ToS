# OGC API da Direção-Geral do Território

## Utilização da API para acesso a dados geográficos

As **OGC API da Direção-Geral do Território (DGT)** permitem o acesso a informação geográfica por aplicações e outros sistemas, através de padrões abertos do **Open Geospatial Consortium (OGC)**.

A API permite consultar e integrar informação geográfica em aplicações, Sistemas de Informação Geográfica (SIG), serviços WEB e fluxos de processamento automatizado.

## Como utilizar

1. Descubra as colecções disponíveis na [Landing Page](https://ogcapi.dgterritorio.gov.pt/).
2. Consulte a [especificação OpenAPI](https://ogcapi.dgterritorio.gov.pt/openapi).
3. Identifique a operação e os parâmetros adequados.
4. Utilize paginação e filtros para evitar transferências desnecessárias.
5. Verifique os metadados e a licença aplicável à colecção.
6. Para utilização automatizada, siga as recomendações de [termos de utilização](termos.md).

!!! note "Estado da informação"
    Esta documentação complementa a informação técnica disponibilizada pela API. A especificação OpenAPI constitui a referência para as operações e os parâmetros actualmente suportados pelo serviço.
